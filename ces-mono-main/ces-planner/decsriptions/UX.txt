The app should open to a landing page. 

the first question on the landing page should be customer block that collects customer company name, customer name, customer phone number customer email address and CMMC level desire. Such customers  should be selectable from the set of all  Customer objects, perhaps via a drop-down. 

Once a customer is created the user will be presented with a button to generate an SI baseline. 
 
When the button to generate a SI baseline is pressed the app will run through the questions appropriate for an SI baseline and the app will save the results. 

Once an SI baseline is generated or Selected, the user will be on the landing page and will be able to create a RR scenario specific question set. 

Once the RR scenario specific question set is created, The user will be presented with a button to answer the readiness recon questions (those questions were generated in rhe prior step). The user will have an auto fill button to answer the readiness recon questions. If the auto fill option is selected, the app will answer the RR questions with reasonable values based on information in the Si baseline. all of the questions will be answered, the CE readiness Posture object saved, and the user returned to the landing page with that phase completed. 

Note, the auto fill buttons are for development purposes, and will be hidden at some point. Deisgn for this. 

Once the readiness posture  file is created successfully, the user will have an option on the landing page to generate mission plan.

When the user presses the generate mission plan button, the application will draw from the required resources, run the transform generator and create the outputs for the mission  plan.
