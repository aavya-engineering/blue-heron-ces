# BHD brand tokens — for the demo:show slide theme

Source: BHDsite `app/globals.css` (read-only extract, 2026-09-05). Logos copied to
`docs/demo/design/brand/` (bhd-logo.svg dark-on-light, bhd-logo-white.svg for dark

## Palette

| Token | Value | Role |
|---|---|---|
| navy | `#1a2332` | primary brand dark |
| navy-deep | `#0f1923` | darkest background |
| navy-mid | `#152030` | mid background / cards on dark |
| accent (gold) | `#f5b74a` | THE brand accent — headings, highlights, borders |
| accent-glow | `rgba(245,183,74,0.25)` | glow/shadow around gold elements |
| border-dark | `rgba(245,183,74,0.15)` | hairline borders on dark |
| text-on-dark | `#e8ecf2` | body text on navy |
| muted-on-dark | `rgba(185,195,212,0.75)` | secondary text on navy |
| bg (light) | `#f9fafb` / surface `#ffffff` | light-mode page/surface |
| text (light) | `#0c111d`, muted `#4b5565` | light-mode text |
| nav-bg-scrolled | `rgba(10,22,40,0.92)` | translucent navy chrome |

## Type & motion

- Font: `'Roboto', system-ui, -apple-system, 'Segoe UI', Arial, sans-serif`
- Transition: `300ms cubic-bezier(0.4, 0, 0.2, 1)`
- Shadows: light `0 4px 24px rgba(0,0,0,0.06)`, dark `0 4px 24px rgba(0,0,0,0.3)`,
  hover `0 12px 40px rgba(0,0,0,0.12–0.45)`

## Read of the brand voice

Dark navy surfaces with restrained gold accents; translucent navy chrome with a gold
hairline; generous shadows; smooth 300 ms easing. Defense-industry sober, not flashy —
gold is used sparingly for emphasis, never as a fill flood.
