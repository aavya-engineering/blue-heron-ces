# Planner → Muster shift: contractor package

This package scopes the work to bring Muster (generation 2) to output parity with Planner (generation 1): the same
outputs, with far fewer questions. Revision 2026-10-21.

## Reading order

1. **`00-PREAMBLE.md`**: what Planner and Muster are, the parity rule, where the code lives, scope, and how to work
   with BHD. Read it first.
2. **`02-DECISIONS.md`**: the ten scope decisions, with rationale and implications. Read it before the backlog so the
   priorities make sense.
3. **`01-GAP-BACKLOG.md`**: the parity matrix, the MG items with "Done when" criteria, the out-of-scope items, Planner
   defects not to copy, and the wave plan. This is your working list.

Before you start any item, set up your environment with `ces-onboarding/` (chapters 05 §8 and §9, 06, and 08 for live
tenant work).

For the runnable sim path see the repository root (it supplements this package and does not supersede it).
