# T3 Wiring — Evidence Package Export Button

The ResultScreen's "Export Evidence Package" button should call `exportEvidencePackage` from `src/features/export/evidencePackageService.ts`, passing the current session (from Dexie via `db.interview_sessions.get(sessionId)`), the assessed party, the scored posture (already computed for display), the conservative score, and any optional SPRS result or artifacts. The function assembles the package, validates it against `public/schemas/evidence-package.schema.json` (throwing on any schema violation to prevent export of an invalid package), and triggers the browser download as `evidence-package-<party-slug>-<date>.json`. Wiring is deferred to avoid parallel edits with the scoring and UI branches active on this session; the ResultScreen component and its handler import path are the only touch points when the wiring commit is ready.
